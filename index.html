Đồng bộ lên GitHub

Mỗi lần soạn thảo, toàn bộ dữ liệu được tự động ghi vào một tệp JSON trong kho GitHub của bạn (sau khi ngừng gõ ~2 giây). Mở trang trên máy khác là có lại dữ liệu.

Bảo mật: bệnh án là dữ liệu nhạy cảm. Hãy lưu dữ liệu ở kho Private (riêng tư), không đặt tên/thông tin định danh bệnh nhân vào kho công khai. Mã token chỉ lưu trong trình duyệt này.
Cách tạo token (1 phút)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: chọn Only select repositories → chọn đúng kho dữ liệu.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Tạo xong, copy token dán vào ô trên.
